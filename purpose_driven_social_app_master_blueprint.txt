============================================================
1. PRODUCT NORTH STAR
============================================================

A temporary, purpose-aware digital space where people can communicate,
collaborate, coordinate in the physical world, use tools relevant to their
objective, and automatically close the space when its lifecycle ends.

Core formula:
Purpose + People + Tools + Time + Realtime + Lifecycle
= Purpose-driven temporary group.

The product is NOT a WhatsApp clone.

The group is the central product object. Every group knows:
- why it exists
- who belongs to it
- which tools are enabled
- when it starts
- when it ends
- what information is most important
- which permissions each member has

CORE LOOP
1. Authenticate.
2. Create profile.
3. Search exact usernames.
4. Become friends.
5. Create temporary group.
6. Select purpose.
7. Select duration.
8. Invite only existing friends.
9. Enable purpose-specific modules.
10. Collaborate in realtime.
11. Coordinate physically when location is enabled.
12. Complete the objective.
13. Expire.
14. Archive.
15. Purge according to retention rules.

NON-NEGOTIABLE EXPERIENCE RULES
- Premium visual hierarchy.
- No emoji-based UI.
- No cheap iconography.
- No random gradients.
- No generic AI dashboard appearance.
- No unnecessary glassmorphism.
- Motion must communicate state.
- Sound and haptics must be subtle and optional.
- Battery usage must be aggressively optimized.
- Location must be opt-in, temporary and group-scoped.
- Backend owns authorization and lifecycle.

============================================================
2. PREMIUM DESIGN LANGUAGE
============================================================

The visual language should feel intentional, spatial, calm, modern and
expensive without relying on decoration.

DESIGN PRINCIPLES

1. Hierarchy
Important content is visually dominant.

2. Spatial calm
Use deliberate margins and a consistent 4/8-point spacing rhythm.

3. Controlled depth
Use elevation and blur only when they explain layering.

4. Purposeful motion
Animate state changes, not everything.

5. One icon language
Use custom SVG/professional vector icons with consistent stroke weight,
optical size and corner treatment.

6. Typography first
Typography and spacing establish hierarchy before color.

7. Tactile polish
Use short, contextual haptics and sounds.

8. No cheap AI aesthetic
Avoid:
- emoji icons
- meaningless charts
- random gradients
- repeated generic cards
- excessive shadows
- excessive glassmorphism

SUGGESTED TOKENS
- Spacing: 4-point base / 8-point rhythm.
- Radius: 8, 12, 16, 24.
- Primary: indigo-violet family.
- Secondary: teal family.
- Text: deep blue-black.
- Muted: slate.
- Touch targets: generally 44–48 pt.
- Motion: roughly 150–450 ms depending on interaction.

============================================================
17. BATTERY OPTIMIZATION
============================================================

Battery is a product requirement.

Never:
- poll GPS every second by default
- transmit every GPS coordinate
- call routing for every point
- keep every GPS point in React state
- continue after arrival
- continue after expiry

ADAPTIVE STRATEGY

Stationary:
Very low frequency and suppress unchanged updates.

Walking:
Moderate cadence plus movement threshold.

Driving:
Adaptive speed/relevance-aware cadence.

Far from destination:
Normal cadence.

Approaching:
Increase relevance only if needed.

Near destination:
Short high-relevance burst if required.

Arrived:
Stop tracking.

RULES
1. Distance thresholds.
2. Time thresholds.
3. Movement detection.
4. Lower accuracy when possible.
5. Suppress duplicate coordinates.
6. Throttle network updates.
7. Separate GPS sampling from network transmission.
8. Native background location services.
9. Respect Android background restrictions.
10. Respect iOS background restrictions.
11. Stop on session end.
12. Stop on group expiry.
13. Measure real battery use.

LOCATION PIPELINE

Native GPS
→ local movement filter
→ active session validation
→ meaningful update
→ backend current-location state
→ controlled realtime subscribers
→ UI

Routing is a separate path.

→ active operations stop
→ location sessions stop
→ EXPIRED
→ notify

- location permission revoked
- low-power mode
- Valhalla unavailable
- map unavailable
- realtime available while map unavailable
- concurrent admin edits
- task edit/completion race
- push arriving after expiry
- new device
- interrupted file upload
- username changes
- incorrect device clock
- long background period
- no optional modules
- network changes

Every edge case needs:
- deterministic state
- user-visible explanation
- recovery path
