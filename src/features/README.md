# Feature Modules

This directory contains domain-driven feature slices for the Neram platform.

## Planned Feature Slices
- `auth/`: Authentication flow, Google OAuth, session refresh, hardware token storage.
- `profile/`: User profile view, edit, exact search interface.
- `friends/`: Friend requests, friendships list, blocking management.
- `groups/`: Temporary group creation, signature circular duration dial, group shell, settings.
- `chat/`: Realtime group messaging stream, replies, read states, attachments.
- `tasks/`: Collaborative task tracking, statuses, priorities, multi-assignees.
- `files/`: Document and photo gallery, signed download URLs, upload manager.
- `events/`: Group events, countdown timers, destinations, reminders.
- `polls/`: Single-vote decision polls, option creation, live results.
- `location/`: On-device movement filtering, adaptive GPS tracking, arrival detection.
- `maps/`: MapLibre Native vector maps, OpenFreeMap tiles, custom markers, Valhalla route polyline.
- `notifications/`: In-app notification center and push notification handling.

*Note: Per STEP 2 instructions, concrete implementations will be built in their respective development phases.*
